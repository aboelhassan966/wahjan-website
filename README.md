# وهجان — موقع الويب

موقع عربي متجاوب بهوية وهجان، مكتوب باستخدام HTML وCSS وJavaScript دون مكتبات خارجية.

## التعديل
كل المحتوى والتصميم داخل `index.html`. افتح الملف ثم زر القلم لتعديله، واحفظ عبر Commit changes. يمكن تعديل الصور والخطوط والألوان والأقسام وإضافة عناصر بصرية وحركات.

## المعاينة
افتح index.html محليًا في Chrome، أو فعّل GitHub Pages من Settings → Pages، واختر main والمجلد /(root).

## حدود النسخة
- نموذج التواصل يفتح تطبيق البريد برسالة جاهزة؛ لا يرسل أو يخزن البيانات تلقائيًا.
- الشعار نص مؤقت إلى حين توفير الشعار الرسمي.
- رقم 250,000+ مأخوذ من وصف المشروع ويحتاج مراجعة المالك قبل الاعتماد.
- هذه واجهة بديلة للمشروع الأصلي الذي كانت صفحاته مقطوعة؛ لا تتضمن تطبيق Android أو خادمًا خلفيًا.
